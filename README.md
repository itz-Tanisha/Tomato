# Tomato -  Food Ordering Website using React JS

This repository contains an Online Food Ordering Website developed using the React JS. 
The website offers a convenient way for users to order food online from the restaurant at the comfort of their home.
<br> 
<br> 

## Technologies Used
- **Frontend:** React.js, HTML, CSS<br>

<br>

## Key Features 

- **User Authentication:** Users can register and log in to their accounts.
- **Category Browsing:** Browse food items by categories.
- **Shopping Cart:** Add, update, and remove items from the shopping cart.
- **Checkout:** Seamless checkout page for placing orders.
- **Responsive Design:** The website is mobile-friendly and adapts to different screen sizes.

<br>

## Start the app

### Frontend

```shell
cd frontend
npm i
npm start
```
